## バックエンドのfs用にプロジェクトディレクトリの設定および取得を追加

バックエンドのfs用として、以下の２つの機能を追加する。

* プロジェクトディレクトリの設定(fs:setProjectDirectory)  
  + プロジェクトディレクトリのパスを引数として、設定する。
* プロジェクトディレクトリの取得(fs:getProjectDirectory)
  + 設定されているプロジェクトディレクトリのパスを返す。

現在は内部的に値を保持するのみとします。
ただし、ProjectContextでopenProjectが呼ばれたときに、バックエンドにも設定します。
