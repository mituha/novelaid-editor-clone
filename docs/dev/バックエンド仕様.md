# バックエンド仕様

本プロジェクトは Electron を活用したデスクトップアプリケーションであり、メインプロセスがバックエンドの役割を担います。

## 技術スタック
- **アーキテクチャ**: Electron (Main/Renderer/Preload)
- **言語**: TypeScript, Node.js
- **主要ライブラリ**: `electron`, `electron-log`, `electron-updater`

## メインプロセスの役割
メインプロセス（`src/main/main.ts`）は以下の責務を持ちます：
1. **アプリライフサイクル管理**: アプリの起動、終了、ウィンドウの生成。
2. **システム連携**: ファイルシステムへのアクセス、ネイティブダイアログの表示。
3. **自動アップデート**: `electron-updater` を使用した更新通知とダウンロード。
4. **ネイティブメニュー**: `src/main/menu.ts` によるプラットフォーム固有のメニュー管理。

## IPC (Inter-Process Communication) 仕様
メインプロセスとレンダラープロセス間の通信は、`ipcMain` と `ipcRenderer` を介して行われます。セキュリティのため、レンダラープロセスからは `preload.ts` で公開されたブリッジ API を通じてのみアクセス可能です。

### 提供されている IPC ハンドラー

| チャンネル名 | 機能概要 | 引数 | 戻り値 |
| :--- | :--- | :--- | :--- |
| `get-app-path` | 特殊なディレクトリのパスを取得 | `name: string` (userData, home) | `string \| null` |
| `ensure-dir` | ディレクトリの存在確認と作成 | `directoryPath: string` | `boolean` |
| `read-json` | JSON ファイルを読み込む | `filePath: string` | `any` (存在しない場合は null) |
| `write-json` | JSON ファイルを書き込む | `filePath: string`, `data: any` | `boolean` |
| `select-directory`| フォルダ選択ダイアログを表示 | なし | `string \| null` (選択されたパス) |
| `list-files` | 指定パス内のファイル一覧を取得 | `directoryPath: string` | `{ name: string, isDirectory: boolean }[]` |
| `read-file` | テキストファイルを読み込む | `filePath: string` | `string` (UTF-8) |
| `write-file` | テキストファイルを書き込む | `filePath: string`, `content: string` | `boolean` |
| `fs:setProjectDirectory` | プロジェクトディレクトリを設定 | `path: string` | `boolean` |
| `fs:getProjectDirectory` | プロジェクトディレクトリを取得 | なし | `string \| null` |

## プリロードスクリプト (Preload Script)
`src/main/preload.ts` は、`contextBridge` を使用して安全な API を `window.electron` として公開します。

### 公開 API (`window.electron.ipcRenderer`)
レンダラープロセスからは以下のようにメソッド形式で呼び出すことができます：
- `selectDirectory()`
- `listFiles(directoryPath)`
- `readFile(filePath)`
- `writeFile(filePath, content)`
- `getAppPath(name)`
- `ensureDir(directoryPath)`
- `readJson(filePath)`
- `writeJson(filePath, data)`
- `setProjectDirectory(path)`
- `getProjectDirectory()`

## ウィンドウ管理
- デバッグ環境では `REACT_DEVELOPER_TOOLS` を自動インストールします。
- 外部 URL へのリンクは、システム規定のブラウザで開くように設定されています（`setWindowOpenHandler`）。
- メニュー構成は `src/main/menu.ts` で OS (macOS/Windows/Linux) や環境 (dev/prod) に応じて動的に生成されます。
